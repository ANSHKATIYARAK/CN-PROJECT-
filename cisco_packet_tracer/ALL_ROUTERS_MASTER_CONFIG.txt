HOW TO USE IN CISCO PACKET TRACER:
1. Click on the respective router in Packet Tracer workspace.
2. Select the "CLI" tab.
3. If prompted "Would you like to enter the initial configuration dialog? [yes/no]:", type "no" and press Enter.
4. Press Enter until you see Router>
5. Copy the exact block below for that router and paste it directly into the CLI.
6. The router will automatically configure hostnames, interfaces, loopbacks, and OSPF!

ROUTER 1: CTS-CORE1 (Area 0 Backbone Spine Router)
========================================================================================
enable
configure terminal
hostname CTS-Core1
ip routing
interface Loopback0
 ip address 10.0.0.1 255.255.255.255
 ip ospf 1 area 0
 no shutdown
exit
interface GigabitEthernet0/0/0
 description 100G Trunk to CTS-Core2
 ip address 10.0.0.1 255.255.255.252
 ip ospf network point-to-point
 ip ospf cost 1
 no shutdown
exit
interface GigabitEthernet0/0/1
 description 100G Trunk l1 to SJT-ABR (Area 10)
 ip address 10.0.0.5 255.255.255.252
 ip ospf network point-to-point
 ip ospf cost 1
 no shutdown
exit
interface GigabitEthernet0/0/2
 description 100G Trunk l2 to TT-ABR (Area 10)
 ip address 10.0.0.9 255.255.255.252
 ip ospf network point-to-point
 ip ospf cost 1
 no shutdown
exit
interface GigabitEthernet0/1/0
 description 10G Trunk l5 to Admin-ABR (Area 30)
 ip address 10.0.0.21 255.255.255.252
 ip ospf network point-to-point
